# Testdokumentasjon

## Full systemtest

Åpne [jira-miro-full-test-plan.xlsx](jira-miro-full-test-plan.xlsx) for den komplette testlisten og statusoversikten for Jira ↔ Miro-integrasjonen.

Rapporten inneholder:

- Testoversikt med samlet status
- Testliste for drift, Jira → Miro, Miro → Jira, sticky-konvertering, app/UI og reliabilitet
- Dekning mellom test-ID-er og funksjonsområder
- Egne visuelle tester for Blocker-prioritet, Hotfix-felt, work type-farger og prioritetsikoner
- Funksjonsdekning som kobler kildefiler og funksjoner til konkrete test-ID-er og status

Åpne først fanen `Testoversikt`. Detaljene ligger i `Testliste`.
